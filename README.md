# ROAM CENTER
 
## Project Description
ROAM CENTER is a dynamic, single-page web application designed to demonstrate advanced DOM manipulation techniques using JavaScript. The application allows users to explore various activities, manage a personalized adventure list, and toggle between light and dark themes for an enhanced user experience.

## Features Implemented
- **Responsive Navigation**: Includes a dropdown menu and a hamburger icon for mobile devices.
- **Theme Switching**: A toggle button to switch between Light and Dark modes.
- **Text Manipulation**: Dynamically update content on the page via user interaction.
- **Dynamic List Management**: Add activities to a list from cards and remove them by clicking.

- **Real-time Search**: Filter adventure list items instantly as you type.
- **Interactive Activity Cards**: Premium cards with select functionality that integrates with the dynamic list.
- **Input Capture**: Capture and display user input in real-time.

## What the Project Demonstrates
The ROAM CENTER project showcases the ability to:
- Select and manipulate DOM elements using `getElementById` and `querySelector`.
- Implement interactive features using modern Event Listeners.
- Dynamically create, modify, and remove HTML elements.
- Apply conditional styling and theme management using Tailwind CSS classes.
- Handle responsive design for seamless cross-device usage.
